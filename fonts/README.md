Fonts for the cover page and headings. They are not built into Typst, so they
live here:

- TUM Neue Helvetica (`TUMNeueHelvetica-*.ttf`), the TUM corporate font. All
  rights belong to the Technical University of Munich. It is not covered by
  the MIT License of this repository. Use it only as TUM allows, see
  https://www.tum.de/cd.
- New Computer Modern Sans (`NewCMSans10-*.otf`), GUST Font License,
  https://ctan.org/pkg/newcomputermodern
- TeX Gyre Heros (`texgyreheros-regular.otf`), GUST Font License,
  https://ctan.org/pkg/tex-gyre-heros

The template uses TUM Neue Helvetica and falls back to New Computer Modern
Sans and TeX Gyre Heros if it is missing.
